# signal-pinger

Расписание для сервиса [«Сигнал»](https://signal-theta-three.vercel.app) — триггеры продаж
из открытых государственных реестров Кыргызской Республики.

Зачем нужен отдельный репозиторий: планировщик Vercel на тарифе Hobby запускает задачи
раз в сутки, а событие госзакупки полезно в тот же день. Здесь лежит только расписание:
каждые 10 минут вызывается `/api/refresh` сервиса, тот идёт в реестры и рассылает
подписчикам новые события в Telegram.

Кода продукта и данных подписчиков здесь нет. Адрес и секрет хранятся в
Settings → Secrets and variables → Actions:

- `PING_URL` — адрес обновления, например `https://signal-theta-three.vercel.app/api/refresh`
- `CRON_SECRET` — тот же секрет, что в переменных окружения Vercel

Проверить вручную: вкладка **Actions** → **ping** → **Run workflow**.
